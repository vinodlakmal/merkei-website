CASE STUDY / TELECOM SOFTWARE

eSIM Inventory Platform

A B2B platform for managing eSIM stock, carrier package orders and prepaid reseller balances in one system.

Full-stack development, telecom integrations and production operations

The challenge

Resellers needed to allocate eSIM stock, apply carrier packages and track charges without losing sight of which dealer owned each order. A delayed carrier reply could leave an order in doubt, so a browser timeout could not be treated as a failed purchase.

What we built

Inventory and reseller portals

Managed blank eSIM stock, package catalogues and ICCID lookups. Built English and Chinese dealer and admin interfaces for ordering, top-ups, inventory and reporting, with desktop and mobile checks.

Carrier APIs and messaging

Integrated package enquiries, recharges and subscriptions. Supported OTP delivery through SMPP/CUG messaging and account-scoped Socket.IO updates.

Order and wallet reliability

Used persisted order jobs, status polling, stock reservations and duplicate-request protection. Kept uncertain carrier results separate from confirmed failures so operators could reconcile them before retrying.

Access and pricing separation

Applied server-side role and ownership checks. Separated wholesale cost visibility from dealer-facing prices and tested that restricted data did not appear in search results or API responses.

Deployment and operations

Containerized the Node.js and SQLite application with Docker Compose on Ubuntu. Kept data outside the application image and documented readiness checks, staged cutover and rollback. Added scheduled encrypted backups, restore checks and health alerts.

Used Git and GitHub for version control, scripted pre-release checks and isolated regression testing with simulated carrier responses. Production changes were approved separately from development and testing.

Stack: Node.js, Express, JavaScript, SQLite, REST APIs, Socket.IO, SMPP, Docker, Docker Compose, Ubuntu, Cloudflare and GitHub.
